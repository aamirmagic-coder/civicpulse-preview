# Sukuma! brand application — CivicPulse

**Product:** CivicPulse  
**Descriptor:** Community Intelligence  
**Parent brand:** Sukuma! — “Stand Up! We build together.”

## Selected working direction
Applied as the default working direction from the supplied proposed options: **Brand Guide 1 — Phoenix Kinetic Rise** with **Pairing A — Modern Precision**. The supplied board describes this direction as dynamic, modern, future-focused, with colors for premium tech and rapid growth. This is a working selection, not a claim that the proposed board was formally approved.

## Palette
- Midnight canvas: #0B0F19 (product interface foundation)
- Deep Cyan Sky: #087EAA (primary interaction)
- Azure Wing: #328CC1 (supporting blue)
- Vibrant Blaze: #F36B32 (warm accent)
- Core Fire: #C74620 (deep flame)
- Kinetic Teal: #0FA6A6 (secondary interaction)
- Amber Glow: #F4B544 (highlight)
- White: #F9FAFB; secondary text: #9CA3AF

The product's existing dark executive-dashboard foundation is retained; the phoenix mark and primary interactive colors now reflect the Sukuma direction. The light theme remains available.

## Logo use
- Use the phoenix symbol as the compact app mark and favicon.
- Keep the mark's aspect ratio; do not stretch, redraw, or place text inside it.
- Use the full Sukuma! lockup for parent-brand communications; use “CivicPulse · Community Intelligence” for the product header.
- Ensure the mark remains clear on dark and light surfaces.

## Typography
Use the existing system sans-serif stack as the practical implementation of Modern Precision: crisp, high-legibility headings, compact labels, and clear hierarchy.

## Guardrails
This is a proposed-options board, not a complete final brand manual. Exact font files, logo clear-space rules, minimum sizes, and approved logo exports were not specified in the supplied board. Do not imply those have been formally approved.
